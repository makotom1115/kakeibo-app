家計簿管理アプリ
概要

本アプリは、日々の収入・支出を記録し、家計の状況を簡単に把握できるWebアプリケーションです。
収支データの登録・編集・削除や、期間指定による検索、残高表示機能を備えています。

制作目的
PythonおよびFlaskを用いたWebアプリケーション開発の理解を深めることを目的として制作しました。
CRUD処理やデータベース操作、Webアプリの基本的な構成について実践的に学習することを重視しています。

主な機能
収入・支出データの登録
収入・支出データの編集・削除
費目の管理機能
期間指定によるデータ検索
残高（収支差額）の表示
入力値チェック（バリデーション）

使用技術
Python
Flask
PostgreSQL
HTML / CSS
Git / GitHub
Render（デプロイ）

工夫した点
直感的に操作できる画面構成を意識し、入力・一覧表示の流れをシンプルに設計
入力ミスを防ぐためのバリデーションを実装
期間検索機能により、過去の収支を効率的に確認できるよう改善
データベースを利用し、データを永続的に管理できるように設計

今後の課題
グラフ表示機能の追加による収支の可視化
スマートフォン対応（レスポンシブデザイン）の強化
過去データをもとにした簡易的な収支予測機能の実装
